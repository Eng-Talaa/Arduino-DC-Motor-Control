# DC Motor Control Using Arduino and L293D

This project demonstrates the control of four DC motors using an Arduino Uno and dual L293D H-Bridge motor drivers through a Tinkercad simulation. The system executes a predefined motion sequence consisting of forward, backward, right, and left movements.

## Hardware Components

- Arduino Uno R3
- 2 × L293D H-Bridge Motor Drivers
- 4 × DC Motors
- Breadboard
- 9V Battery
- Jumper Wires
